# Day 72 — Markdown Blog Engine (Flask)

**120 Days of Code** | NIT Rourkela | Mechanical Engineering

## What this is
A full stack blog engine where posts are written in
Markdown and rendered as styled HTML pages.

## How to run
```bash
pip3 install flask markdown2
python3 app.py
```
Then open http://localhost:5000

## Features
- Write posts in Markdown files
- Auto renders to styled HTML
- Tag filtering and search
- Reading time estimates
- Syntax highlighted code blocks
- RSS-style post listing
